# ECPack.wl: A Mathematica Package for Elliptic Curves over the Rationals and Finite Fields

This repository has the Mathematica code for Elliptic Curves over rational and finite fields. It also includes notebooks with examples from books by Lozano, Husemöller, Washington, Silverman, and Weinzierl, as well as miscellaneous examples.

More details can be found at: https://arxiv.org/abs/2611.20548
